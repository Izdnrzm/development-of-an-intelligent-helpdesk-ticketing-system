# Requirements

## Functional requirements 
1. The system shall allow users to submit helpdesk tickets through a web interface.
2. The system shall automatically classify submitted tickets into predefined categories.
3. The system shall assign a priority level (Low, Medium, High, Critical) based on ticket content.
4. The system shall generate a summarized version of the ticket for support staff.
5. The system shall recommend appropriate responses using a Large Language Model.
