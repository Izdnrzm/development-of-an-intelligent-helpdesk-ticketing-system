# Intelligent Helpdesk Ticketing System
The Development of an Intelligent Helpdesk Ticketing System Using Large Language Models project aims to design and develop a web-based helpdesk system that leverages Natural Language Processing (NLP) and Large Language Models (LLMs) to automate the handling of IT support tickets. 

# Problem Statement
Modern helpdesk and IT service desk operations is the manual processing of support tickets, particularly during ticket classification, prioritization, and routing, support agents must manually read each ticket description, determine the issue category, assign a priority level, and forward the ticket to the appropriate resolver group. In the number of support request increase, this process becomes time consuming, inconsistent, and prone to human error. Research by classifying the unstructured IT service desk tickets using ensemble of classifiers reports that manual classification of IT service desk tickets may result in tickets being routed to the wrong resolution group. Incorrect ticket assignment leads to reassignment, unnecessary resource utilization, and delays in any problem resolution. The study further highlights that these issues will affect productivity and customer satisfaction.
